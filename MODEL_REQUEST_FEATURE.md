# 🖨️ Функция "Заказать печать" для 3D моделей

## ✅ Что было добавлено

На странице 3D моделей (`/charity/models`) теперь каждая модель имеет кнопку **"Заказать печать"**, которая открывает форму заявки с уже заполненными данными о модели.

## 🎯 Функционал

### 1. **Кнопка "Заказать печать"**
На каждой карточке модели добавлена новая кнопка рядом с кнопкой скачивания:
- 🎨 Оранжевый цвет для контраста
- ✅ Иконка галочки
- 💫 Hover эффекты с подъемом и тенью
- 📱 Адаптивный дизайн для мобильных

### 2. **Модальное окно с формой**
При клике на кнопку открывается красивое модальное окно:
- 🖼️ Превью выбранной модели с изображением
- 📋 Информация о модели (название, описание, характеристики)
- 📝 Форма заявки с предзаполненными полями
- ❌ Кнопка закрытия
- 🎭 Плавная анимация появления/исчезновения

### 3. **Автозаполнение формы**
Форма заявки автоматически заполняется:
- **Ссылка на модель** - URL файла модели (если есть)
- **Что нужно напечатать** - название модели
- **Комментарий** - категория и описание модели

### 4. **Автозакрытие после отправки**
После успешной отправки заявки:
- ✅ Показывается сообщение об успехе
- ⏱️ Через 2 секунды модальное окно автоматически закрывается
- 🔄 Форма сбрасывается для новых заявок

## 🚀 Как использовать

### Для пользователей:

1. **Откройте страницу моделей:**
   - Перейдите на `/charity/models`
   - Или через меню: Благотворительность → 3D Модели

2. **Выберите модель:**
   - Просмотрите доступные модели
   - Найдите нужную модель

3. **Нажмите "Заказать печать":**
   - Кликните на оранжевую кнопку
   - Откроется модальное окно

4. **Заполните форму:**
   - Ссылка на модель уже заполнена
   - Название модели уже указано
   - Добавьте свои контактные данные
   - Укажите детали заказа

5. **Отправьте заявку:**
   - Нажмите "Отправить заявку"
   - Дождитесь подтверждения
   - Окно закроется автоматически

### Для разработчиков:

**Пример использования компонента формы:**

```vue
<template>
  <CharityRequestForm 
    :initial-model-link="modelUrl"
    :initial-wish="modelName"
    :initial-comment="modelDescription"
    @success="onSuccess"
  />
</template>

<script setup>
import CharityRequestForm from '@/components/charity/RequestForm.vue'

const modelUrl = '/models/toy.stl'
const modelName = 'Развивающая игрушка'
const modelDescription = 'Игрушка для детей 3-5 лет'

function onSuccess() {
  console.log('Заявка отправлена!')
}
</script>
```

## 📱 Адаптивность

### Desktop (> 768px):
- Кнопки в ряд, 50/50
- Модальное окно: 700px ширина
- Превью модели: горизонтально

### Mobile (< 768px):
- Кнопки в столбик, на всю ширину
- Модальное окно: 95vh высота
- Превью модели: вертикально
- Изображение: на всю ширину

## 🎭 Анимации

### Модальное окно:
- **Открытие:**
  - Fade in (opacity 0 → 1)
  - Scale + TranslateY (0.9 + 20px → 1 + 0)
  - Длительность: 300ms

- **Закрытие:**
  - Fade out (opacity 1 → 0)
  - Scale + TranslateY (1 + 0 → 0.9 + 20px)
  - Длительность: 300ms

### Кнопки:
- Hover: translateY(-2px) + shadow
- Active: translateY(0)
- Transition: 200ms

## 💡 Особенности

### Блокировка прокрутки:
При открытии модального окна прокрутка body блокируется:
```typescript
document.body.style.overflow = 'hidden'  // открытие
document.body.style.overflow = ''         // закрытие
```

### Клик вне модального окна:
Модальное окно закрывается при клике на overlay (затемненный фон).

После успешной отправки окно закрывается через 2 секунды, давая время увидеть сообщение об успехе.
