# Страница Поддержки

## Описание

Создана новая страница поддержки организации, где можно собирать пожертвования на различные направления деятельности, аналогично существующей странице благотворительности для 3D-печати.

## Реализованные функции

### 1. Store для управления данными поддержки
- **Файл**: `src/stores/support.ts`
- **Функции**:
  - `fetchSupportGoals()` - получение целей поддержки с сервера
  - `createSupportGoal()` - создание новой цели (для админ-панели)
  - `updateSupportGoal()` - обновление цели
  - `deleteSupportGoal()` - удаление цели

### 2. Страница поддержки
- **Файл**: `src/views/SupportView.vue`
- **URL**: `/support`
- **Функции**:
  - Hero-секция с общей статистикой
  - Фильтрация целей по приоритету (все/высокий/средний)
  - Карточки целей с:
    - Иконкой и приоритетом
    - Описанием
    - Примерами использования средств
    - Прогресс-баром
    - Кнопкой "Поддержать"
  - Секция общей поддержки проекта
  - Блок информации о безопасности и прозрачности

### 3. Данные целей поддержки
- **Файл**: `src/data/support_goals.json`
- **Направления**:
  1. **Транспортное обеспечение** 🚐
     - Трансфер глухих на предприятия
     - Организация экскурсий
  2. **Питание участников** 🍽️
     - Обеды для участников мастер-классов
     - Кофе-брейки на семинарах
  3. **Расходные материалы** 📦
     - Материалы для занятий и мастер-классов
  4. **Техническое оснащение** 💻
     - Проекторы, компьютеры, оборудование
  5. **Аренда помещений** 🏢
     - Конференц-залы, мастерские
  6. **Услуги переводчиков** 🤟
     - Сурдопереводчики для мероприятий
  7. **Маркетинг и информирование** 📢
     - Буклеты, баннеры, соц. сети
  8. **Обучение команды** 🎓
     - Курсы повышения квалификации

### 4. Навигация
- Добавлена ссылка в главное меню: `AppHeader.vue`
- Обновлена секция поддержки на главной странице: `SupportSection.vue`
  - Кнопка "Сделать пожертвование" теперь ведет на `/support`
- Добавлен маршрут в роутер: `src/router/index.ts`

## Структура данных

### SupportGoal
```typescript
interface SupportGoal {
  id: number
  title: string
  description: string
  target_amount: number
  current_amount: number
  category: string
  priority: 'high' | 'medium' | 'low'
  icon?: string
  examples?: string[]
}
```

## Использование

### Для пользователей
1. Перейти на страницу `/support` через меню "Поддержка"
2. Выбрать интересующее направление
3. Нажать кнопку "Поддержать" для совершения пожертвования

### Для администраторов
```typescript
import { useSupportStore } from '@/stores/support'

const store = useSupportStore()

// Создание новой цели
await store.createSupportGoal({
  title: 'Новая цель',
  description: 'Описание',
  target_amount: 100000,
  category: 'transport',
  priority: 'high',
  icon: '🚐',
  examples: ['Пример 1', 'Пример 2']
})

// Обновление прогресса
await store.updateSupportGoal(1, {
  current_amount: 50000
})
```

## API endpoints (для backend)

- `GET /support-goals` - получение всех целей
- `POST /admin/support-goals` - создание новой цели
- `PATCH /admin/support-goals/:id` - обновление цели
- `DELETE /admin/support-goals/:id` - удаление цели

## Дизайн

Страница использует фиолетово-синюю цветовую схему (gradient: #6366f1 → #8b5cf6 → #d946ef), отличающуюся от оранжевой схемы благотворительности, что помогает визуально разделить два направления.

## Запуск

```bash
npm run dev
```

Страница будет доступна по адресу: `http://localhost:5176/support`
