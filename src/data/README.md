# Примеры данных для благотворительного проекта

В этой папке находятся JSON файлы с примерами данных, которые используются как fallback при недоступности API или для демонстрационных целей.

## 📁 Файлы данных

### Новые файлы (контент для подвкладок):

#### `articles.json` - Статьи
**5 примеров статей** о проекте, руководства и истории успеха.

**Структура:**
- `id` - уникальный идентификатор
- `title` - заголовок статьи
- `content` - полный текст статьи
- `author` - автор публикации
- `date` - дата публикации (ISO format)
- `image` - URL изображения (optional)
- `category` - категория статьи (optional)

**Категории статей:**
- Истории успеха
- Обучение
- Статистика
- О проекте
- Безопасность

---

#### `videos.json` - Видео
**8 примеров видеоматериалов** - туториалы, истории и мастер-классы.

**Структура:**
- `id` - уникальный идентификатор
- `title` - название видео
- `url` - ссылка на видео (YouTube и т.д.)
- `description` - описание содержания
- `thumbnail` - URL превью изображения (optional)
- `date` - дата добавления (ISO format)
- `duration` - длительность в формате "MM:SS" (optional)

**Темы видео:**
- Настройка принтера
- Истории детей
- Обзор моделей
- Настройка слайсера
- Встречи волонтеров
- Мастер-классы
- Экскурсии
- Безопасность

---

#### `materials.json` - Файлы для скачивания
**10 примеров материалов** - документы, инструкции, шаблоны.

**Структура:**
- `id` - уникальный идентификатор
- `title` - название файла
- `type` - тип файла (pdf, docx, xlsx, pptx, zip, etc.)
- `fileUrl` - путь к файлу
- `description` - описание содержимого
- `date` - дата добавления (ISO format)
- `size` - размер файла (optional)

**Типы файлов:**
- PDF - руководства, каталоги, отчеты
- DOCX - шаблоны документов
- XLSX - таблицы настроек
- PPTX - презентации
- ZIP - архивы с шаблонами

**Категории материалов:**
- Руководства для волонтеров
- Каталоги моделей
- Презентации проекта
- Технические документы
- Шаблоны документов
- Инструкции
- Отчеты

---

#### `print_models.json` - 3D Модели для печати
**12 примеров моделей** - игрушки, развивающие материалы, адаптивные устройства.

**Структура:**
- `id` - уникальный идентификатор
- `name` - название модели
- `description` - подробное описание
- `category` - категория модели
- `fileUrl` - путь к STL файлу (optional)
- `imageUrl` - URL превью изображения (optional)
- `printTime` - примерное время печати (optional)
- `materialType` - рекомендуемый материал (optional)
- `date` - дата добавления (ISO format)

**Категории моделей:**
- Развивающие игрушки - пазлы, конструкторы
- Адаптивные устройства - ручки для письма, держатели
- Конструкторы - наборы для сборки
- Органайзеры - подставки, хранилища
- Игрушки - фигурки, машинки
- Учебные принадлежности - подставки, линейки
- Транспорт - машинки, каталки
- Музыкальные инструменты - свистульки
- Украшения - браслеты, аксессуары
- Аксессуары - держатели для телефонов
- Настольные игры - шахматы, игры

**Рекомендуемые материалы:**
- **PLA** - самый популярный, безопасный, легкий в печати
- **PETG** - более прочный, для изделий требующих износостойкости
- **TPU** - гибкий материал для мягких деталей

## 🔄 Использование

Эти данные автоматически загружаются store'ом (Pinia) как fallback при недоступности API:

```typescript
async function fetchArticles() {
  try {
    const data = await http.get<Article[]>('/articles')
    articles.value = data
  } catch (error) {
    trackApiError(error, 'fetchArticles')
    // fallback to bundled data
    articles.value = articlesData as Article[]
  }
}
```

Это обеспечивает работу приложения даже без подключения к backend'у.

## 📝 Обновление данных

Для обновления примеров данных:
1. Отредактируйте соответствующий JSON файл
2. Убедитесь, что структура соответствует интерфейсам в `src/stores/charity.ts`
3. Проверьте валидность JSON
4. Перезапустите dev server
