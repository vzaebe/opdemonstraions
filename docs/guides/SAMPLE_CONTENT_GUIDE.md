## 🎯 Как посмотреть примеры

### Вариант 1: Запустить приложение

```bash
npm run dev
```

Затем откройте в браузере:
- http://localhost:5173/charity/articles - Статьи
- http://localhost:5173/charity/videos - Видео
- http://localhost:5173/charity/materials - Материалы
- http://localhost:5173/charity/models - 3D Модели

### Вариант 2: Через выпадающее меню

1. Откройте главную страницу
2. Наведите курсор на пункт меню **"Благотворительность"**
3. Появится красивое выпадающее меню с 4 разделами
4. Выберите нужный раздел

## 🔐 Управление контентом через админку

1. Откройте `/admin`
2. Выберите вкладку: **Статьи**, **Видео**, **Файлы** или **3D Модели**
3. Увидите список примеров из JSON файлов
4. Можете добавлять, редактировать и удалять элементы

## 🎨 Особенности

### Автоматический Fallback
Store автоматически загружает данные из JSON файлов, если API недоступен:

```typescript
try {
  const data = await http.get<Article[]>('/articles')
  articles.value = data
} catch (error) {
  // Автоматически загружаются примеры из JSON
  articles.value = articlesData as Article[]
}
```

### Красивые изображения
Все примеры используют изображения с Unsplash для демонстрации. Можете заменить на свои!

### Реалистичный контент
Все тексты, описания и данные написаны в контексте реального благотворительного проекта 3D-печати.

## 🔄 Обновление примеров

Чтобы изменить примеры данных:

1. Откройте нужный файл в `src/data/`:
   - `articles.json`
   - `videos.json`
   - `materials.json`
   - `print_models.json`

2. Отредактируйте JSON (добавьте/удалите/измените элементы)

3. Сохраните файл

4. Перезапустите dev server (если запущен):
   ```bash
   npm run dev
   ```
