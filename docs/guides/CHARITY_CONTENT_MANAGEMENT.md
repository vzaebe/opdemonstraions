# Управление контентом благотворительности

## 📋 Обзор

В систему добавлены новые разделы для управления контентом благотворительного проекта:

- **Статьи** - публикации и новости
- **Видео** - видеоматериалы и туториалы
- **Материалы** - файлы для скачивания (PDF, DOC, и т.д.)
- **3D Модели** - STL файлы для печати

## 🎨 Выпадающее меню

При наведении на пункт меню **"Благотворительность"** появляется красивое выпадающее меню с 4 подразделами:

### Дизайн меню:
- ✨ Иконки для каждого раздела с уникальными цветами
- 🎯 Плавные анимации появления/исчезновения
- 📱 Адаптивный дизайн для мобильных устройств
- 🖱️ Hover эффекты с трансформацией и подсветкой
- 🎨 Градиентные фоны для иконок

### Разделы:
1. **Статьи** 📖 - Полезные публикации
2. **Видео** 🎥 - Видеоматериалы
3. **Материалы** 📄 - Файлы для скачивания
4. **3D Модели** 🖨️ - STL файлы для печати

## 🔐 Админ-панель

В админ-панели (`/admin`) добавлены 4 новых вкладки для управления контентом:

### Вкладка "Статьи"
**Поля:**
- Заголовок (обязательно)
- Содержание (обязательно)
- Автор
- Категория
- URL изображения
- Дата (автоматически)

**Функции:**
- ✅ Создание статьи
- ✏️ Редактирование
- 🗑️ Удаление
- 📋 Список всех статей с сортировкой

### Вкладка "Видео"
**Поля:**
- Название (обязательно)
- URL видео (обязательно)
- Описание
- URL превью
- Длительность
- Дата (автоматически)

**Функции:**
- ✅ Добавление видео
- ✏️ Редактирование
- 🗑️ Удаление
- 🔗 Прямая ссылка для просмотра

### Вкладка "Файлы"
**Поля:**
- Название (обязательно)
- Тип файла (PDF, DOC, DOCX, XLS, XLSX, PPT, PPTX, ZIP, другое)
- URL файла (обязательно)
- Описание
- Размер файла
- Дата (автоматически)

**Функции:**
- ✅ Загрузка файла (через URL)
- ✏️ Редактирование информации
- 🗑️ Удаление
- ⬇️ Прямое скачивание

### Вкладка "3D Модели"
**Поля:**
- Название (обязательно)
- Категория (обязательно)
- Описание
- URL STL файла
- URL изображения модели
- Время печати
- Тип материала (PLA, ABS, PETG)
- Дата (автоматически)

**Функции:**
- ✅ Добавление модели
- ✏️ Редактирование
- 🗑️ Удаление
- ⬇️ Скачивание STL файла

## 💾 Store (Pinia)

### Новые интерфейсы:

```typescript
interface Article {
  id: string
  title: string
  content: string
  author: string
  date: string
  image?: string
  category?: string
}

interface Video {
  id: string
  title: string
  url: string
  description: string
  thumbnail?: string
  date: string
  duration?: string
}

interface Material {
  id: string
  title: string
  type: string
  fileUrl: string
  description: string
  date: string
  size?: string
}

interface PrintModel {
  id: string
  name: string
  description: string
  category: string
  fileUrl?: string
  imageUrl?: string
  printTime?: string
  materialType?: string
  date: string
}
```

### API методы:

Для каждого типа контента доступны:
- `fetch{Type}()` - получение списка
- `create{Type}(payload)` - создание
- `update{Type}(id, updates)` - обновление
- `delete{Type}(id)` - удаление

## 🚀 Использование

### Добавление контента через админку:

1. Откройте `/admin`
2. Выберите нужную вкладку (Статьи/Видео/Файлы/3D Модели)
3. Заполните форму в верхней части страницы
4. Нажмите кнопку "Добавить"
5. Контент появится в списке ниже и на публичной странице

### Редактирование:

1. В списке найдите нужный элемент
2. Нажмите "Редактировать"
3. Форма редактирования появится внизу страницы
4. Измените нужные поля
5. Нажмите "Сохранить" или "Отмена"

### Удаление:

1. Найдите элемент в списке
2. Нажмите кнопку "Удалить"
3. Подтвердите действие во всплывающем окне
