# Отчёт об исправлениях

## Что сделано
- Исправлена работа менеджера галереи: защищены сценарии без выбранной картинки, нормализованы сохраняемые данные, добавлены более надёжные превью и кнопки.
- Поправлен компонент диаграмм: убраны обращения к неопределённым точкам, расчёт кривых и областей теперь безопасен при пустых данных.
- Улучшена валидация видеоссылок: корректно извлекаются идентификаторы YouTube/Vimeo/RuTube.
- Наведён порядок в админ-панели: данные пользователя берутся из стора, формы проектов/ресурсов типизированы, добавлено описание ресурса, обработчики приводят статус и суммы к корректным типам.
- Устранены тайпинги 3D-блока: добавлены типы three/troika, установлен `@types/three`.
- Обновлена система логирования: сервер оборачивает async‑маршруты, пишет расширенные ошибки и отлавливает необработанные исключения; фронт `trackApiError` теперь логирует структурировано.
- Убраны sass-предупреждения: заменены `darken()` на `color.adjust`.
- Устранено предупреждение Rollup о циклическом импорте: `api` из print-service подключается напрямую в сторах.

## Проверки
- `npm run type-check`
- `npm run build` (успешно; остаётся предупреждение о размере одного чанка)
