## UI Kit (единый набор компонентов)

Цель: убрать разрозненные “самописные” кнопки/инпуты/карточки по проекту и
свести базовые UI-примитивы в одно место.

### Принципы
- Компоненты UI kit **не знают про бизнес-логику** (только внешний вид + удобные props).
- Все стили опираются на токены из `src/assets/styles/variables.scss`.
- Если нужен новый элемент — сначала добавляем в UI kit, потом используем в фичах.

### Компоненты
- `UiButton` — кнопка (variants + loading)
- `UiInput` — input
- `UiSelect` — select
- `UiCard` — контейнер/карточка
